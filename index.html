PERSONAL AUDIT LOG BACKUP

監査ログを、
本人の管理下に。

Hyperliquid NOSEND Backup は、運営者本人の監査ログを、本人が所有・管理する Google Drive に私的にバックアップするための OAuth アプリです。

利用対象は運営者本人だけです。一般利用者の登録・第三者のアカウントの受付は行いません。

データの取り扱いを確認

用途と運営方針

01

私的な記録の保全

目的は監査ログの保存と、必要時の本人による確認です。この公開サイトには、注文・送金・取引の実行機能はありません。

02

必要な権限だけ

バックアップに必要な最小範囲の Google Drive 権限を用いる方針です。実際の要求スコープは未確認のため、特定の権限だけが設定済みとは表明しません。認可前に同意画面で確認してください。

03

本人のためだけに利用

ユーザーデータの販売、広告配信・広告ターゲティングへの利用、広告事業者やデータ仲介業者への提供は行いません。

この公開ページと実装の状態

このサイトで提供するもの：アプリの用途説明とプライバシーポリシーです。Google ログイン、OAuth コールバック、バックアップ処理、データの閲覧・削除の画面はありません。

未確認のもの：バックアップ実装の稼働状況、実際の要求スコープ、保存期間の自動制御です。説明ページの公開は、これらの機能の実装完了や稼働確認を意味しません。

将来変更する場合：機能やデータの取り扱いを変更する前に、この説明とポリシーを更新します。自動削除や一般向け提供を、実装済みの機能または確定した提供予定として案内しません。

GitHub の公開ページに機密データは含みません

この公開リポジトリとページには、OAuth クライアント ID・Secret、アクセストークン・更新トークン、API キー、認証ファイル、監査ログ本文、取引履歴・残高などの取引情報を掲載しません。公開ページのソースにあるのは説明文と表示用ファイルだけです。

アプリ独自の広告、アクセス解析、Cookie、入力フォーム、外部スクリプトは使用していません。配信基盤である GitHub によるアクセス情報の取り扱いは、GitHub のプライバシー声明に従います。

問い合わせ・利用停止・削除

ページの記載に関する連絡先は、運営者が管理する このリポジトリの Issues です。Issues は公開されます。ログ、取引情報、認証情報、個人情報は投稿しないでください。非公開の問い合わせメール窓口は、このページでは設けていません。

本人によるアクセス権の解除、Drive 上のバックアップと管理環境内のコピーの削除については、プライバシーポリシーの削除手順をご覧ください。

このアプリは個人が運営するもので、Google または Hyperliquid の公式サービス・提携サービスではありません。Google による OAuth アプリの確認・審査の完了や承認を保証するものではありません。
