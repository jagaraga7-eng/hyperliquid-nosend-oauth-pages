制定・最終更新日：2026年10月17日

本ポリシーは、運営者 jagaraga7-eng が、運営者本人だけを利用者とする Google Drive 監査ログバックアップ用途の OAuth アプリについて定めるデータ取り扱い方針です。一般向けサービスとして第三者の利用・データ受付は行いません。

1. 対象と現在の状態

この GitHub Pages サイトは、説明とポリシーを公開する静的なサイトです。訪問者の Google アカウントへの接続、Google API の呼び出し、バックアップデータの受け取りは行いません。

バックアップ実装の稼働状況、具体的な要求スコープ、保存期間の自動制御は、この公開ページでは確認済みと表明しません。以下のアプリ側の取り扱いは運営方針であり、未確認の機能が実装済みであることを示すものではありません。機能を追加・変更する場合は、利用前に記載を更新します。

2. 取り扱うデータと利用目的

OAuth を利用したバックアップ時には、次の情報を必要な範囲で取り扱う方針です。

  • 本人がバックアップ対象とした監査ログ：本人の記録保全と、必要時の確認のため。
  • バックアップファイルや保存先の識別情報、処理に必要なメタデータ：対象ファイルの保存・管理のため。
  • Google のアクセストークンや更新トークン等の認可情報：本人が許可した Google Drive 操作のため。

対象ログに個人情報や取引に関する記録が含まれる場合も、本人の私的な保全以外には使用せず、GitHub の公開リポジトリや公開ページには掲載しません。Google アカウントのパスワードを、このサイトが受け取ることはありません。

3. 最小権限と本人の同意

バックアップに必要な最小範囲の Google Drive 権限に限定する方針です。具体的なスコープは未確認であり、Drive 全体へのアクセスが技術的に制限済みであることや、特定のスコープが設定済みであることは保証しません。

本人は認可前に Google の同意画面で、アプリ名と要求権限を確認してください。用途に不要な権限がある場合は認可せず、設定を見直します。Google Drive の権限の種類は Google の公式説明で確認できます。

4. 利用・共有の制限

Google API から得た情報の利用・他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従い、本ページに明記した本人用バックアップの目的に限定する方針です。

ユーザーデータを販売しません。広告配信、広告ターゲティング、信用評価、AI モデルの学習には利用せず、広告事業者、データ仲介業者、情報再販業者には提供しません。保存先は本人が管理する Google Drive とし、Google による処理には Google のプライバシーポリシーが適用されます。本人以外への共有や一般公開は行いません。法令により開示が必要な場合は、その必要な範囲に限って対応します。

5. 保存・保護と管理責任

運営者と利用者は同一人物です。本人が保存先の Google Drive とバックアップ処理に使う管理環境を管理し、認可情報やログへのアクセスを本人に限定する方針です。認可情報は管理環境内で扱い、公開ソース、公開ページ、公開 Issues に含めません。

ログの保存は本人の監査・確認に必要な期間とし、不要になったバックアップと管理環境内のコピーは本人が手動で削除します。固定の保存日数や自動削除の実装は確認されていないため、一定期間後の自動消去を保証しません。利用をやめる場合は次の手順でアクセス権と保存データをそれぞれ処理します。

6. 利用停止・権限解除・データ削除

  1. バックアップの継続を止める：本人の管理環境で、このバックアップ用の処理・定期実行を利用している場合は停止します。既存の別用途の BOT や注文処理を、この公開サイトが操作することはありません。
  2. Google のアクセス権を解除する：Google アカウントのサードパーティ接続から Hyperliquid NOSEND Backup を選び、アクセス権を削除します。手順は Google の公式ヘルプを参照してください。
  3. バックアップを削除する：本人の Google Drive で対象のバックアップファイルを削除します。完全な削除が必要な場合は、対象を十分に確認してからゴミ箱内の該当ファイルも削除します。Google 側の保管・復元の扱いは Google の仕様に従います。
  4. 管理環境内のコピーを削除する：このバックアップ用途で保存したローカルコピーや認可情報がある場合は、本人が対象を確認して削除します。別用途で保持すべき原本・設定を誤って削除しないでください。

権限の解除だけでは、すでに保存したファイルやコピーは削除されません。この公開サイトには、自動削除機能や削除依頼フォームはありません。本人利用のため、削除は本人が保存先と管理環境で直接行います。

7. 公開サイトのアクセス情報

本サイト独自の Cookie、広告、アクセス解析、外部スクリプト、入力フォームは使用していません。OAuth クライアント ID・Secret、トークン、API キー、認証ファイル、監査ログ、取引履歴、残高などの機密データは、公開リポジトリにも公開ページにも含めません。

ホスティング事業者 GitHub は、配信やセキュリティのために IP アドレス等のアクセス情報を扱う場合があります。詳しくは GitHub のプライバシー声明をご覧ください。
